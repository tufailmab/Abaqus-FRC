  <h1>Abaqus-FRC: CAD Specimens for Fiber-Reinforced Composites</h1>

  <p>This repository contains some of the CAD files representing fiber-reinforced composite (FRC) specimens. These files are generated using <strong>visual programming</strong> or <strong>Python Scripting</strong> and exported in <code>.iges</code> format, compatible with Abaqus and other CAD/CAE software.
  All lectures (not about generating these files, but focuses on modeling and simulating fiber-reinforced concrete in ABAQUS, such as working with them after importing into the software) are publicly available in the following YouTube playlist:
  </p>

  <h2>Features</h2>
  <ul>
    <li><strong>CAD Specimens:</strong> A small set of representative fiber-reinforced composite geometries.</li>
    <li><strong>Visual Programming Models:</strong> Some examples created via graphical design workflows.</li>
    <li><strong>IGES Format:</strong> All models are exported as <code>.iges</code> files, ready to be imported into Abaqus or other CAD/CAE software.</li>
  </ul>

  <h2>Usage Instructions</h2>
  <ol>
    <li>Clone or download this repository to your local machine.</li>
    <li>Open the <code>.iges</code> files using CAD software such as:
      <ul>
        <li>Abaqus/CAE</li>
        <li>SolidWorks</li>
        <li>CATIA</li>
        <li>Fusion 360</li>
      </ul>
    </li>
    <li>You can use these CAD models for visualization, modification, or as input for Abaqus simulations.</li>
  </ol>

  <h2>Requirements</h2>
  <ul>
    <li>CAD software that supports <code>.iges</code> files (e.g., Abaqus/CAE, SolidWorks, CATIA, Fusion 360)</li>
  </ul>
